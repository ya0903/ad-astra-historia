**Out of scope:** Tech tree overhaul (deferred), UI bugs (separate pass), ancient era data.

## 1. Map Visuals — Biomes, Rivers & Lakes

### Problem
`biomes.geojson`, `rivers.geojson`, and `ocean.geojson` are not committed and never downloaded automatically. The rendering code in `WorldMap.tsx` exists but silently fails when files are missing. The existing edge-blur blending (`biomes-edge-blur` layer) is too subtle to create a natural terrain feel.

### Solution

#### 1.1 Auto-download on server start
- Check for required GeoJSON files (`biomes.geojson`, `rivers.geojson`, `ocean.geojson`, `lakes.geojson`) on Express server startup.
- If any are missing, run `download.mjs` automatically before serving the game.
- Add `ne_50m_lakes.geojson` to the download script (Natural Earth 50m lakes dataset).

#### 1.2 Buffer zone biome blending
A build-time preprocessing script (`shared/eras/generateBiomeBuffers.mjs`) using `@turf/buffer`:

- For each biome polygon in `biomes.geojson`, generate 3 concentric buffer rings:
  - **Inner ring:** 30km buffer, opacity 0.25
  - **Middle ring:** 70km buffer, opacity 0.12
  - **Outer ring:** 120km buffer, opacity 0.05
- Buffer ring colours use a midpoint blend between the biome colour and the adjacent terrain (e.g. desert outer ring → ochre-to-olive transition towards grassland).
- Output: `biomes-blended.geojson` — a single FeatureCollection containing original polygons + all buffer rings, each tagged with `bufferLevel` (0=core, 1-3=rings) and `opacity`.
- The `/api/game/biomes` endpoint serves this blended file.

#### 1.3 Rivers & lakes rendering
- **Rivers:** Already implemented in `RiversLayer.tsx`. Just needs `rivers.geojson` present. Enhance with width variation based on `scalerank` property (major rivers wider than tributaries).
- **Lakes:** New `LakesLayer.tsx` component — filled polygons with `fill-color: rgba(56,189,248,0.3)` and a soft border. Rendered below city labels, above biome fills.

#### 1.4 Layer ordering (bottom to top)
1. Background (`#0a1628`)
2. Hillshade (terrain elevation)
3. Biome buffer rings (outer → inner, lowest opacity first)
4. Biome core fills
5. Ocean mask
6. Country fills (semi-transparent)
7. Country borders
8. Lakes (filled)
9. Rivers (lines)
10. Infrastructure, cities, labels

## 2. Deterministic Country Database (Modern Era)

### Problem
Country stats (population, GDP, sectors) are partially hardcoded with gaps (some countries show 0 population) or generated by AI at runtime. This makes the game unpredictable and wastes API calls on data that should be static.

### Solution

#### 2.1 Static database file
`shared/countryData.ts` — a single typed export covering all ~195 modern countries.

```typescript
export interface CountryBaseData {
  // Identity
  iso3: string
  name: string
  continent: string
  subregion: string

  // Demographics
  population: number              // total (2023)
  populationGrowthRate: number    // annual %
  urbanisationRate: number        // % urban
  medianAge: number

  // Economy
  gdp: number                    // nominal USD
  gdpPerCapita: number           // nominal USD
  gdpGrowthRate: number          // annual %
  sectorAgriculture: number      // % of GDP
  sectorIndustry: number         // % of GDP
  sectorServices: number         // % of GDP
  debtToGdpRatio: number         // %
  inflationRate: number          // %

  // Development
  hdi: number                    // 0-1
  educationIndex: number         // 0-1
  giniCoefficient: number        // 0-100

  // Military
  activePersonnel: number
  defenceSpendingPct: number     // % of GDP
  nuclearCapable: boolean

  // Government
  governmentType: string         // democracy | autocracy | monarchy | theocracy | military_junta | communist | federal_republic
  corruptionIndex: number        // 0-100 (higher = more corrupt)

  // Geography
  areaKm2: number
  landlocked: boolean
  strategicPassages: string[]    // e.g. ['suez', 'hormuz']
}
```

#### 2.2 Data sources
Compiled from publicly available 2023 data:
- World Bank (GDP, population, sectors, urbanisation)
- IMF (debt, inflation, growth)
- UNDP (HDI, education, Gini)
- SIPRI (military spending, personnel)
- Manual curation for government types, nuclear status, strategic passages

#### 2.3 Integration
- `gameStore.ts` → `initializeCountry()` reads from `countryData.ts` instead of the partial lookup tables and AI generation.
- The existing GDP growth simulation, stability drift, and sector mechanics continue to mutate from these real baselines.
- AI is no longer called for any hard data. It is only used for: advisor chat, action narrative text, event flavor text.

## 3. Living World Simulation Engine

### Problem
The world is static between player turns. Countries don't act autonomously, no organic events occur, and there's no sense of a living geopolitical landscape.

### Solution: Probabilistic World Tick Engine

#### 3.1 Country AI personalities
Each country gets a disposition profile stored alongside its game state:

| Trait | Range | Effect |
|-------|-------|--------|
| `aggression` | 0-100 | Likelihood of military threats, territorial claims, power projection |
| `diplomacy` | 0-100 | Tendency to form alliances, negotiate, mediate conflicts |
| `economicFocus` | 0-100 | Prioritises trade deals, sanctions, economic leverage over military |
| `stability` | 0-100 | Internal cohesion, resistance to coups and unrest |
| `unpredictability` | 0-20 | Chance of out-of-character actions (the "America threatens Denmark" factor) |

- **Seeded from country database** (e.g. USA: aggression 75, unpredictability 18; Switzerland: aggression 15, diplomacy 85, stability 92).
- **Drift over time** based on events, leadership changes, economic conditions, and player actions (±1-3 per major event).

#### 3.2 Weekly world tick
New function `worldTick()` in `shared/worldSimulation.ts`, called by `gameStore.advanceDate()` every week.

**Step 1 — Tension evaluation:**
For every country pair where relations < `neutral`:
- Roll against `aggression + powerImbalance + historyModifier + random(0, unpredictability)`
- Possible outcomes (weighted, not deterministic):
  - **Escalate** (threaten, sanction, mobilise) — weighted by aggression
  - **De-escalate** (back down, negotiate) — weighted by diplomacy + power gap
  - **Wildcard** (unexpected action) — weighted by unpredictability

**Step 2 — Opportunity generation:**
Countries with high diplomacy may propose:
- Alliance formation (shared rivals, geographic proximity)
- Trade agreements (complementary economies)
- Peace talks (ongoing conflicts with exhaustion)
- Joint infrastructure projects
- Target selection: weighted random from eligible candidates based on shared interests.

**Step 3 — Internal events:**
Based on stability + economic health, probabilistic rolls for:
- **Coups:** low stability + military strength > civilian control capacity
- **Elections / transitions:** democracies on ~4-year cycle, autocracies on death/overthrow
- **Economic crises:** high debt + low growth + high inflation
- **Reform movements:** high education + low political freedom + moderate stability
- **Separatism:** low stability + ethnic tensions (modeled via region data)

Each event has a base probability (e.g. coup: 2% base per week when stability < 20) modified by context. Never guaranteed.

**Step 4 — Chain reactions with decay:**
Events can trigger follow-on events, each link with decreasing probability:
- War breaks out → 60% chance neighbor condemns → 30% chance sanctions → 15% chance military intervention
- The chain can fizzle at any point, producing different cascades each playthrough.

#### 3.3 Event taxonomy
All world tick events are typed:

```typescript
type WorldTickEventType =
  // Diplomacy
  | 'alliance_proposed' | 'alliance_formed' | 'alliance_dissolved'
  | 'trade_deal_proposed' | 'trade_deal_signed' | 'trade_deal_collapsed'
  | 'peace_talks_initiated' | 'peace_treaty_signed'
  | 'diplomatic_incident' | 'embassy_recalled' | 'sanctions_imposed'
  // Military
  | 'territorial_claim' | 'military_mobilisation' | 'border_skirmish'
  | 'war_declared' | 'ceasefire' | 'arms_deal'
  | 'military_exercise' | 'naval_standoff'
  // Internal
  | 'coup_attempt' | 'coup_success' | 'election_held'
  | 'protests_erupt' | 'reform_passed' | 'crackdown'
  | 'economic_crisis' | 'economic_boom'
  | 'separatist_movement' | 'leadership_change'
  // Wildcard
  | 'unexpected_ultimatum' | 'surprise_summit' | 'defection'
  | 'intelligence_leak' | 'humanitarian_crisis'
```

#### 3.4 News generation (expanded)
Every world tick event produces a news item via expanded `newsGenerator.ts`:
- **Template-based headlines** — Each event type has 3-5 headline templates with country name slots. Deterministic, no AI needed.
- **Optional AI flavor body** — If an AI model is configured, send event context for a 1-2 sentence narrative body. If no AI, use template fallback. News works either way.
- **Weekly volume:** 3-8 items per week, filtered by importance so the feed doesn't flood.
- **Categories:** diplomacy, military, economy, politics, disaster, world.

#### 3.5 Effect on game state
World tick events modify the shared game state:
- Relations between countries shift (±5-20 per event)
- GDP affected by trade deals (+), sanctions (-), wars (--)
- Stability affected by internal events
- Military readiness changes during mobilisations/wars
- Alliances tracked in `diplomacyState.alliances`
- All changes are deterministic once the random roll resolves — no AI in the loop for stat mutations.

#### 3.6 Example playthrough sequence
**Week 1:** Russia (aggression 70, unpredictability 12) rolls escalation against Ukraine → "military exercise" near border. NATO countries get a chain reaction roll → 55% verbal condemnation fires for 3 of 5 allies.

**Week 2:** China (economicFocus 80) proposes trade deal to Brazil (complementary economies). Brazil's diplomacy score (60) makes acceptance likely → deal signed, both get GDP modifier.

**Week 3:** Egypt (stability 35) rolls internal event → protests erupt. Chain: 40% government crackdown fires → stability drops further. Neighboring countries watch.

**Week 4:** USA (unpredictability 18) rolls wildcard → territorial claim against... weighted random picks Greenland (Denmark). Denmark refuses (stability 90). NATO emergency summit roll: 25% fires. Relations USA-EU drop by 15.

Each week feels different. Same world, different story every game.

## What AI Is Still Used For

After this work, AI is only called for:
- **Advisor chat** — Player asks questions, AI responds with game context
- **Action narrative** — Player takes an action, AI describes the outcome story
- **Optional news flavor** — AI writes creative body text for headlines (fallback templates if no AI)

All hard data, all world simulation decisions, all stat mutations are deterministic/probabilistic with no AI dependency.
